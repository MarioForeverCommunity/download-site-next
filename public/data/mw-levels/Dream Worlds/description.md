DREAM WORLD 是本人旧作品dream2010的完全翻新版本，除了前期的关卡是由dream2010的原关卡修改而成的之外，其余的关卡都是全新的。
这个作品有以下的特点：
1.富有意境。意境作为新时代mw作品的一个必不可少的元素，能够吸引大家的眼球，在玩这个关卡的时候享受到更多的乐趣。
2.难度跨度大。从1-1到final battle，几乎从十分简单上升到了非常难的层次，许多关卡都十分具有挑战性，比如说这个名为“决战快乐云”的6-3：

3.沿袭了N's land的两大特色设计：第0关和mini game
本次的mini game 的抽奖游戏减少了，更多的是有趣的挑战关卡。
