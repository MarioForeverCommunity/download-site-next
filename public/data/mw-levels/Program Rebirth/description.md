作者的话：

这次的标题，我用了“不忘初心”四个字，这既是对剧情的诠释，也是对我做关时的心境的最好概括。说起开此坑的由来，可能得追溯到我的童年。我只记得我小时候特别喜欢一些极难的马里奥改版，如今细细分析这种喜欢的源头，其实很纯粹，就是通关所获得的极大的满足感。而且在这条路上，圈里还是有很多先驱关卡的。个人认为从出现探照灯弹幕关开始，吧里的关卡一直有向kaizo关演变的倾向，虽然可能出于良心精力舆论等原因，这种倾向一直被压制罢了。前几年的时候我也想过，针对这种难控的异变如何如何反其道而行之，做了很多开放探索性关卡，这也算的上是一次可贵的尝试。但是不久以后就腻了，转而顺应潮流，最后把潮流推向极端。

个人认为提高关卡难度本质上有两条途径，分别是提高操作密度和操作精度。由于MW不像SMW有很多组合键，一定程度上不利于前者的发展，所以MW难关里普遍还是微操关居多。但是高操作量关要是能做好，相比于微操关要不那么“硬核”的多——即只是手速和背板的问题，不需要多高的技术，且观赏性也是十足的。据此，我做出了一些尝试，希望大家能够接受。

然后我来简单地介绍一下这个作品。本作从去年暑假开始制作，至昨天完成，历时半年多。游戏主线有18个部分，且其中将近一半都有一个挑战关附带一个小型解谜关，体量还是很大的，估算一下差不多是RCP的2倍、孤月华章的4倍了。鉴于本作难度极大和我圈现状，初见全通关时间因人而异，平均估计得25小时左右，所以我设置的每一p就是一个存档，便于你利用零碎时间练练手。前期三关相对比较简单，凑时机的成分较多，是帮助你上手的，中后期关有的简单有的很难，这主要和我做关时的心情有关。最终关分3个部分，难度极大，但是每一部分的流程都分的比较短，cp较多，多死可破（除了最后一部分）。

通关后还有挑战模式等着你（暴论）

除此以外，这个作品还有三大特色——剧情、玩法、bgm。对，你没看错，这个作品里面的bgm都是新的！！！！！这么做一方面也是效仿SMWkaizo关卡，另一方面也是给你们吃一颗定心丸，防止砸键盘等情绪失控行为。剧情属于传统艺能，不多赘述，唯一一点就是结局虽然已经交代的比较清楚了，但是关卡中还有还有一些剧情的细节还是略过的，其中的哲理可以自行解读（希望这次拼错的单词没那么多）。至于玩法，这几个月里我网罗天下放佚作品，考之行事，稽其成败兴坏之理，关卡中的创新必定会让你眼前一亮！个人比较喜欢的关卡有4,5,6，9，12,14，18。
