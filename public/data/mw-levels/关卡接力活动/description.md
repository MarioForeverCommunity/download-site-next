2017年4月15日规则第一版：
1.参加限制：在Marioworker吧等级达到7级者允许参加。
2.每人的参加次数：每人允许制作三关，每次制作关卡并得到认可后会冷却6关（如果你制作了第7关，那么第8-13关将不允许你制作），第1关将会由活动举办方(就是我咯)制作并发布。
3.我该如何参与活动：在第x关完成并投票完毕后或第x关为不合格关卡时，将由组委会成员宣布关于第x+1关或第x关制作竞标开始，在开始之后，满足条件的吧友可以报名，组委会将宣布报名是否成功，在第一个人报名成功后竞标结束，从报名开始时刻开始规定时间内必须完成并上传，并在帖子里公布已经完成，否则视为不合格关卡。
4.不合格关卡：为防止极差关卡的出现，每个关卡制作结束后将开始投票。每位参加过之前关卡制作的人和组委会成员拥有投票权，在组委会指定楼的楼中楼回复以进行投票，可以选择支持或反对。投票结束的条件：该关卡公布完成已经过48小时且投票总数至少为3。在投票结束后如果反对票占总投票数目的30%以上(例如共6人投票，2人反对，反对票占比33%)，则此关宣布废弃，本关制作人失去一次制作机会并进入冷却，如果某人制作了两个不合格关卡，则此人将被取消参加活动的权利。关于不合格关卡的定义将在下文中给出。如果合格则将开始下一关卡的制作。对于不合格关卡，给予选手一次修改机会，选手必须于规定时间内修改好，并重新投票。P.S.:前三关除外，仅由举办方投票决定。
二、关卡制作规定
1.制作的关卡长度和高度相乘应小于24,000格，即24,576,000像素，大于3,000格，即3,072,000像素，否则视作不合格关卡。不合格理由：关卡尺寸不合格。
2.制作关卡应满足最低水平的欣赏性(如蓝鱼在天上和快乐云一起幸福的赛跑就不满足欣赏性)，否则将视作不合格关卡。不合格理由：严重违背欣赏性。
3.每关可以改为与上一关完全不同的场景(城堡、地下关卡除外)，但应自行制作一个大小为20*15格的mfl，并在其中写明剧情(剧情请用英文且语法基本正确)，同关卡一起上传，否则将被视为不合格关卡。不合格理由：与上一关没有衔接性。
4.难度必须成梯度上升(当然平级和略微下降我也没意见)，与上一关关卡难度不能差别太大(谁要在1-1后面放个LG8-P我第一个不服)，否则将视为不合格关卡。不合格理由：关卡难度过高/低。
5.尽量不要出现太过反人类的设计，如成片红花、满地毒蘑菇、锤子雨、一万个快乐云等，否则将被视为不合格关卡。不合格理由：关卡反人类。
6.每关制作后必须要写一个有趣的标题，用英语且无语法错误，并且尽可能有诗意，标题后写明作者名，统一格式：x(这是第x关)+关卡名(少于20字符)#(by 作者名)。不合格标题举例：I’ll give you some color see see.(理由：毫无语法且超字数)，否则视作不合格关卡。不合格理由：看着难受。P.S.:如果选手不想做这项工作，可以由举办方代替选手为关卡随机分配新的名称(如level 1、level 1、level 1等)。
7.为保证平衡性，一个关卡内请勿设计大量易得的绿蘑菇和其他刷命手段，否则视为不合格关卡。不合格理由：严重影响平衡性。
其他
1.MW版本要求：SuperMario Worker 0.24
2.关于boss的制作：想制作boss关的同学，请在制作完成自己申请制作的关卡后再制作一个boss关，大小小于3000格，即3,072,000像素。最好不要在一个普通关卡里以很难打的boss结尾。
3.关于剧情关的制作：想改变场景(如火山到天空)的同学，请在制作完成自己申请制作的关卡后再制作一个剧情关作为衔接，大小为20*15格。P.S.:英文不好的建议用最简单的语言描述剧情然后扔进google翻译。
4.关于mini game和奖励关：不允许制作这两类关卡
5.关于mirror关：不允许制作mirror关
6.关于解谜关和迷宫关：原则上不反对，但是请一定要好好控制难度，如果可能请设置第二条可以强过的线路，杜绝“绕关三匝，无路可依”的情况出现，尤其是解谜关！
7.关于以前的关卡：禁止使用任何曾经公开发布过的关卡，否则视为不合格关卡。
8.关于规定时间：在北京时间6月30日之前，做关时间为14天，评论时间为7天，修改时间为7天；在北京时间7月1日及以后，做关时间为72小时，评论时间为48小时，修改时间为24小时。
