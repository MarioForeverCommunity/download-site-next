01. 游戏介绍

本作品是在马里奥同人游戏Super Mario Worker Project上制作的关卡集，需要使用Super Mario Worker Project 1.6.5运行游玩此作品。

本作品包含了九个风格各异的世界，其中八个世界为主线关卡，另外的一个世界为附加关卡，作为DLC发布。

主线关卡分为Part 1、Part 2、Part 3三个压缩包。其中Part 1不设密码，Part 2和Part 3设有密码。

Part 1部分为本作品的第一世界，通关该世界后你将得到一个密码，这个密码可以用于解锁Part 2，此外，该密码也是最终密码的一部分。

Part 2部分为本作品在1.0版即发布的六个世界，你可以以任意顺序挑战这六个世界。每个世界后都有最终密码的一部分。

Part 3部分为本作品的最终世界，需要通过最终密码来解锁。

此外，每个世界后得到的密码可以用于解锁该世界对应的奖励和后期发布的DLC内容。

以上提及的密码均为小写字母。

另外，为提高作品的可玩性，本作品中每一关都有三个绿蘑菇供收集。理论上你可以将本作中所有关卡一命绿蘑菇全收集通关。欢迎大家挑战绿蘑菇的全收集并通过关卡。考虑到部分绿蘑菇难以寻找，本作品各关的单关版本被作为对应世界的奖励，可以使用相应的密码解锁。
