**作品简介**

Super Mario Worker Maker是由ƒresh★LAKE制作的马造向MW作品，包含了多样的从易到难的关卡。

v2.0.0在重制初版5关内容的基础上新增了16关的百人团模式，**总计21关**。

**大家的世界**

在本模式中玩家将在工匠自制的大地图上进入关卡并游玩。内容由初版删改而成，调整了2关并重做了3关，**共5关**。

**单关存档**，**不限命**，**难度较大**。

**百人团**

在本模式中玩家将从**100命**起步，依次打通8关，最终完成挑战。作品内共有两轮百人团，每轮8关**共16关**。

**没有任何存档**且**无论发生什么情况作者也不会提供任何存档**，**难度从易到难随机变动**。

**双屏幕**

**关卡机器人**

在百人团团灭了不想重来怎么办？

在百人团模式通过每一关后，你可以得到该关的关卡ID，并将关卡下载到关卡机器人中下载的关卡处。

你可以向别人分享自己喜欢的关卡，或是向大佬询问你团灭后没游玩过的关卡，只需关卡ID即可。

**赞/孬 评价系统**

无论是在大家的世界还是百人团，跟初版一样，在通过每一关后可以在过关界面点赞/点孬，为作者提供即时的反馈。
