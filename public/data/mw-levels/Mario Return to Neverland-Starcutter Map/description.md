**（故事根据真实事件魔改改编）**

那是2014年的暑假，小达来到青岛旅游，并在坐旋转木马的时候认识了阿龙。两人见面一聊起来就情投意合，志向远大，投其所好…于是，小达和阿龙两人在游乐场一起愉快的度过了一天，并每天相约一起玩耍。而在偶然的聊天过程中，阿龙从小达口中得知，小达筹备了一个叫做MRTN的MW作品，但阿龙当时还不知道MW是什么，这让只在信息课上玩过Mario Forever的他有点好奇。于是，阿龙在小达离开青岛的那一天向小达约定:“如果将来我知道了MW是什么，并找到了你，我一定要和你一起合作制作你的这个作品。”

但这件事对于阿龙来说，仿佛是生命中无数有趣的事情之一，很快就被他所忘却掉了。

但直到2年后，对MF感兴趣的阿龙在一次浏览器的搜索当中注意到了MW吧，而且对MW产生了浓厚的兴趣。于是，阿龙给自己起了一个叫做“s小s飞s侠s”的百度ID，加入了MW吧，并在一段时间后进入了MW群。

但当时，刚入吧的阿龙并不懂得如何与大家交流，导致引发了一些不愉快的事情。而当时在群里，有一个名叫“dasasdhba”的吧友也有点看不惯他的举动。但随着时间的推移，das逐渐发现这个叫xfx的吧友很有才华，于是对他的印象逐渐变的好了起来。

后来，xfx邀请das参与了自己的MF作品xfx world和MW作品MWCW，而das也邀请xfx参与了自己的SMMWW和众多MF节日小作，两人也逐渐聊的越来越投机。

日子一天天这样的过去，而xfx在空闲之余也会翻看一些MW老作品，然后截图发到群里作为MW智多星的题目，以让大家回忆起当年的作品。直到2个月前，xfx偶然翻到了一部名叫MRTN的作品。顿时，无数回忆涌上心头，xfx心想:难道，das就是小达吗？

于是，xfx向das发起了私聊。

“das，在吗？”

“咋了（”

“emm…你的MRTN咋只有三个世界…”

“咋突然问这个（”

“就是好奇，感觉这个作品质量还不错结果就烂尾了（”

“啊，这个说来话长了。我在8年前曾经在青岛交了一个朋友，并和他约定一起制作这个作品。但直到现在，我还没有遇到他…”

“你说的这个朋友…”

“和你一个城市是吧（”

“不是，我的意思是…他是不是叫…”

“？”

“叫……阿龙？”

“？？？你…”

“小达，想不到真的是你…”

“阿龙！没想到原来你就是阿龙！”

那一刻，das和xfx宛如兄弟相认，纷纷落泪。而后，xfx决定履行当年的约定，完成MRTN的后续制作。

“但是（”

“但是啥？”

“我做的这3个世界已经跟不上SMWP的时代了吧（（”

“这个你放心，作为拥有desert和MWCW魔改经验的我，这种问题对我来说根本不在话下！”

…

和上面说的一样，在偶然的一次智多星出题中，我注意到了dasasdhba的这部尘封许久的作品和它一直无人问津的w3以及烂尾的作品后半部分。而在玛丽的死对头的一次群直播中，我又看到了这部作品的许多在当时超前的思想与精细的设计，于是这使我萌生了揭开这个作品尘封多年的关卡并完结这部作品的想法。于是在经dasasdhba的同意后，我将dasasdhba原有的4.4时代的关卡增添了许多“现代感”的气息，并将这3个世界的关卡依照难度和主题进行修改和重新编排，分裂成全新的6个世界。与此同时，依照dasasdhba之前的打算，我为本作在此基础上续增了w7和w8，且世界主题也均完全尊重作者的原意。同时，我在制作过程中选择保留了原来的标题版剧情，并在合适的区域通过信息砖展示剧情，以保证游玩畅通。

本作为单世界多关结构，每个世界都有至少5关且关卡数基本随世界数的增长而增长。因此，我在后期世界准备了存档以便于玩家安排挑战的时间。

而经过慎重考虑，本作的8个世界及后期世界的存档将全部开启，无需密码顺序解锁。同时，本作也提供了无限命版本和有限命版本以便于玩家依照自身能力去选择合适的难度挑战。而在每个世界的有限命版本通关后，玩家都会在通关场景获得一个密码，以用于解锁一个特别的奖励(有限命版本存档点同样可以在通关场景获得密码，但有限命版本存档点的命数是对应世界全程命数的一半+3。)。
