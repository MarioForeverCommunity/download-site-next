1、作品总体介绍

1.1作品历史

本作是LLX从2014年暑假规划并于14年8月18日正式开工的一部作品。原规划做15个世界，考虑到难度控制及作者的时间问题，第一次正式发布的版本12个世界。其中8个常规世界，4个附加世界。之后将附加世界单独抽出，作为另一部作品QDCK minus worlds，而QDCK只包含常规世界。同时作品规模将按照原计划扩充至10+5世界。本次将发布QDCK的常规世界最新版本version3.0（10个常规世界），QDCK minus worlds最早会在十周年庆典的时候与大家见面。

Version0.5：包含1~5世界，2016年发布，MW4.4平台。

Version1.0：包含1~8世界，2017年完成，MW4.4平台，未发布。

Version2.0：包含1~12世界，2018年2月12日发布，SMWP0.24平台。

Version3.0：包含1~10共10个常规世界，2020年2月1日发布，**SMWP1.65平台**。

1.2作品内容

本作分为**10个世界共计80个关卡**。常规世界难度起步较低，但有一定的**难度梯度**，适合新手熟练操作，也适合高手探索挑战。

2、作品特色

2.1关卡特色

①复古风

很多关卡中可以看到早期作品的影子，也出现了非常多的经典设计。这也是为了致敬早期作品，响应“不忘初心”的号召。

②创新

许多关卡中都有很多的创新点。有一些关卡是“双终点”的。

③传承

许多经典的单关作品（作者可能是我也可能是别人）在QDCK中除了续作。

2.2特殊关卡

①剧情关

每个世界的之前都会有一个地图关卡向玩家展现这个世界的主题和内容~也会包含一些关卡的小提示~

②彩蛋关

全作共有6个含彩蛋的关卡。这些关卡有类似于一代warp zone的地方，从水管进去后可以读到彩蛋的内容。这6个彩蛋将作为6月27日发布的《十周年合集》里一个奖励的密码，不可错过！当然，这些彩蛋的获取都是有一点难度的，它们究竟在哪些关卡中呢？这需要大家自行探索~

③“三敌人关”

每个世界都有一个只有3种敌人的关卡，而且这些关卡往往比较有趣味性哦！
