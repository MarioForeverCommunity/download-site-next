闲话中的闲话：尽管这部作品我只用了1个月时间完成，但是从去年10月开始，我就已经开始策划这部作品了，原因是那时候制作taoi的灵感枯竭，基本上什么也做不出来，为了能够使我的灵感有用武之地，我就新开坑了这部作品。这部作品的想法是由Black Album 1第一、第二弹的Spring World、Summer World引起的，原计划是在第三弹填上Autumn和Winter，但前面作品的质量太烂，根本没法拿出来，如果大量修改还不如全部重做，于是这部作品就诞生了。。这个版本是1.0版本，有些关卡还没有加上实质内容，例如每个第0关，要等到正式版我估计得到今年暑假的A2。。不过我已经完成了主体部分，已经可以发布了，所以还请大家好好欣赏我的作品，提出一些意见，让这部作品的正式版能够更上一层楼！

作品特色：
1、独特的结构：这部作品共有4世界，采用5数字关+1个palace的结构，相对于早期作品和SMB3作品而言流程中等。每个世界的第3关均为非常规高度的关卡，且流程较长，在关卡中藏着很多隐藏绿蘑菇，看大家的寻找能力！
2、隐藏关：在每个世界里都有一个隐藏关，隐藏关需要在上一关取得某种状态，例如大个子、绿果。。而且你只能挑战一次，如果成功就可以获得一次机会——跳过隐藏关的下一关，或是下一关的大部分，可以说是福利！
3、palace关：在数字关全部通过后，就会进入palace关，palace关也都是非常规关卡，但与第3关不同，它的流程不一定很长，但难度相比数字关而言更大。可以说是一个大挑战！
