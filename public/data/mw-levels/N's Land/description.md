此作品分为easy、normal、hard三个难度版本。
建议新手从easy开始。
建议各位技术不错的朋友从normal开始。
当然如果你有信心的话也可以挑战hard。

本作品架构：
本作品的主体采用了传统的8世界32关架构。
但w1、w4、w7、w8均有特殊的第五关（一般来说是boss战）

作品的两个特色：
1.mini game
在每一个世界的第二关或第三关后面，都有一个有趣的mini game。
分为挑战型和抽奖型两种。
挑战性可以选择放弃，但不能得到奖励。

2.第0关
每个世界的最前面都有一个第0关。
它们是利用超长关卡名技术制作出来的关卡。
请仔细阅读关卡中的文字。
里面可能是剧情，可能是对这个世界的介绍，也可能是迷宫的提示哦！！！
