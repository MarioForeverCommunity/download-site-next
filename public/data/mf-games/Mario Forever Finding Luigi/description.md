Greetings.

This is my first post on the Mario Forever community, and I would like to share the first project I created with Clickteam Fusion 2.5: **Mario Forever: Finding Luigi**. I started working on this project on October 8, 2021, and I completed it more than six months later. The game was developed with Lyh's Rainbow Engine (Version: 0.10.1).

This Mario-Forever-styled game has only four main worlds (altogether 19 stages), two extra levels, and a hidden special world. This game also features a minigame that can only be unlocked if the player collects enough coins in a particular world. Besides, this game is highly inspired by two main Mario games: Super Mario Bros. and Super Mario World by Nintendo®. Many elements from those games, such as growing vines and pulley platforms that are not present in the original Mario Forever, are included in this project. Also, this project is an attempt to recreate the classical atmosphere in vintage Mario games.

The game's story is set after Kamek and Bowser's defeat on Yoshi's Island (not stated in the game). Several years after, Kamek and Bowser seek revenge by trapping Yoshi and kidnapping Luigi, unbeknownst to Mario. Mario, realizing that Luigi has been missing for days, embarks on a new journey to search for his brother.

I hope you enjoy the game!

**Notes:
**

-   Most levels in this game are moderately difficult. Beginners may struggle to complete some of the stages.
-   Large images may not be displayed when the application runs with outdated graphics cards.
-   The display mode of the application is Direct3D 9, meaning that the menu bar and Windows objects (edit boxes) cannot be displayed in full-screen mode.
-   To exit full-screen mode, press Ctrl+E or Esc.
-   It is not recommended to use "A" as one of the controls because it will be used later in the game.
-   Several bugs in the engine (sticky ceiling, inability to jump near obstacles, etc.) are fixed.
