Hey everybody!
I bring to you a new Mario Forever inspired project:
**Mario Eternity**

The game will feature 8 main worlds based on the original Mario Forever
(with a few differences),
with the original Mario Forever soundtrack + a lot of new tracks!
And of course, a lot of new secret worlds as well.

Unlike most Mario Forever fangames, this one is being made in
GameMaker: Studio using CatezeeY/Gatete's SMB1 Engine, heavily
edited. With the ability of using Shaders in GameMaker: Studio, it
is easy to replicate the MF graphics. So it will allow users to
choose if they want the shader or not.
PLUS, it is 16:9 Widescreen!
