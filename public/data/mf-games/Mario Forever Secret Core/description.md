介绍下这个作品：
1.关卡主题：龟壳森林【W1】的东部是一片沙漠，虽然表面看上去很干燥，但是其内部有庞大的暗河。
2.关卡：这部作品分为normal和insane难度，normal难度与world1衔接，insane难度作为挑战模式。W2同W1一样有4关：2-1（金字塔山丘）2-2（危险的金字塔）2-3（陌生的地下水管地带）和2-4（沙漠地下暗河）。normal难度最大的关卡是2-2.insane由于难度过大，因此将4个insane关卡成列在选关界面让玩家选择。
3.难度：normal：难度不大 但是绝对不会太简单，不要掉以轻心。（5/10 稍有难度）
insane：关卡的进阶模式，比normal要难的多，挑战insane，需要掌握MF中的所有技术（尤其是小跳）和怪物的所有特征，有时甚至还要动脑子去解迷，总之难度很大。MF技术不熟练的玩家慎入。（9/10 千难万险）
