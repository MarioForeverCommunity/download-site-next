先前我在SMBX曾经制作MWA和MWB地图，今天MWC已移植到了RE上，（其实只是改个名称而已..）因此游戏风格可能更加偏向SMBX的风格，不过总体风格应该不会跑调。（PIA）游戏采用864x480的宽屏屏幕，看起来将会更加清爽。
游戏的存档设定是每过1关存档一次，大地图选用关卡的模式，只要进入水管就可以开始关卡，过一关可以进入下一关的存档场景。
游戏里还新增了一些原RE没有的NPC如长藤花、扔火球的快乐云、扔刺球的锤子龟、骨头龟、红色飞鸟、喷火铁球（？）、弹跳蘑菇、可融冰等等，大大增加了游戏的乐趣，在一些较为困难的地方加入了1up蘑菇可以防止因GAME OVER而砸屏幕（这我深有感触TAT）
总之这个作品难度我认为不高，适合新手来玩，欢迎前来下载。（啪啪啪）
