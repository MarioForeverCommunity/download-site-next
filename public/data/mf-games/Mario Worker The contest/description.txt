01. INFOS
-----------------------------------------------------------------------------
Mario Worker: The contest is a contest for all users which want to see their levels made with a Mario Worker, remade
in a Mario Forever style. Only the best three can obatin this possibilty.

The best world will be implemented in Mario Forever Remake, with a unique map for it.

03. KEYS
-----------------------------------------------------------------------------
The basic keys are:
X: Run/Shoot Fireballs
Z: Jump/Start a level
ENTER: Start the game
Arrow keys: Move left and right. Press up or down for enter in a vertical pipe.
