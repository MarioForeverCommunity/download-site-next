Mario Forever M-Series v2.0.1 Release
▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
Thank you for downloading and playing my game! It's based on the original Mario Forever made by one person, Michał Gdaniec, known as Softendo and Buziol Games. Mario Forever was inspired from Super Mario games series by Nintendo. The game, levels and maps were created by Tomek839839. Graphics, music and sounds come from the original Mario Forever, Super Mario games, free sources or were created by me.
▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
Website: https://intesit.blogspot.com/
▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
Controls:

Z - Jump
X - Shoot/Run
Left Arrow - Move left
Right Arrow - Move right
Up Arrow - Enter into up pipe/Cursor toogle
Down Arrow - Enter into down pipe/Cursor toogle
These are the default definitions, you can change them by entering to Main menu -> Options -> Controls.
▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
Keyboard shortcuts:

F2 - Restart the game
F3 - Go to Save Game Room
F4 - Go to Main Menu
P - Pause the game
Ctrl + F - Fullscreen mode
Ctrl + W - Window mode
Ctrl + H - Hide the menu bar
Ctrl + J - Show the menu bar
Alt + F4 - Close the game

Save Mover:

Since in version 2.0 of Mario Forever M-Series the save system has been modified, Save Porter program was attached from version 2.0 Beta #1 to Build 9 (can be downloaded separately on https://www.mediafire.com/file/p08qicvjbsr17ym). It transfers the world progress from 1.X versions to 2.X. When you open it, it will detect the highest unlocked world and you will be able to choose the pipe whose progress will be patched.
