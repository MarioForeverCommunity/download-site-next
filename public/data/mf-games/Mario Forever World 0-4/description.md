作品名：Mario Forever World 0-4
作者：水银龟
关卡长度：15000
难度：★★★★★★
这里虽然长度很长，敌人较多，但还是有一些新颖的地方：
1.空中补给红蘑菇：同快乐云差不多，但扔的是红蘑菇，可以增加一点安全系数，以免补给太少过不去，但问题是你能不能接住红蘑菇.........
2.固定红球发射器和齿轮仓：固定的.........小心被阴......
3.黄色喷火花：没什么特别的，只不过是能喷火但是打不死而已了。
4.超级koopa：跟8-4一样，只不过被我修改了几下：血量25格，喷火速度变快，锤子数只有5个，有两个花补给。小提示：打koopa时别着急吃花，有空降红蘑菇，最好在迫不得已的或kooopa快死的情况下用它最好。
