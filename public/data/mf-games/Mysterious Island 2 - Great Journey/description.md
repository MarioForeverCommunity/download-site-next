**【作者的话】**
各位吧友新年好！这次我给大家带来了MRI2的大幅度更新。确实，MRI2的上一版本1.0在某些方面确实做的不尽人意，因此我广泛吸取各吧友的意见，带来了这次更新。首先遭到严重吐槽的就是难度问题和设定问题。当时的我由于有了单关存档就把初始命数狠心的砍掉了2命，发布不久就遭到了强烈谴责。在这半年的时间里，我几乎把MRI2的整改放到了生活的第二位（第一位不用说也知道是啥吧）。我认真测试了每一个关卡并发现了其中的坑点，然后尽力将关卡的难度成直线上升而没有过多的难度突变。并且，MRI2本来是一个难度起步很高的作品，现在也被我调低了起点，大概和原版W3持平吧。
这一路走来特别要感谢的是das.当我发现1.0版本的存档对于某些电脑系统有问题时，das便提出要研究出新的存档机制。最终他成功了，但过程也相当艰苦，大概有十几个小时之久吧。还有游戏中很多各式各样的新颖玩意都是代码大神das做的（我自己做的也有一点），可以说没有了das，MRI2就不会有今天。
这次发布我也抱着很大的信心，能够带给大家全新的游戏体验，因此我也准备在国外宣传自己的作品，不久国外论坛上就可以看到我的发布帖了。
其他的话我也没有什么可说的了，大家玩的开心就好。

**【更新内容】**
***新增内容***
1.新增Bowser Arena（库巴竞技场），目前只开放Bowser Tower，共25层。我相信吧里能打过最高层的寥寥无几（我本人纪录才22）。
2.新增Past World世界
旧版MRI的5-1、7-2、8-1、9-2、6-4关卡经魔改组合成一个草原丛林风格的世界（含大地图）。如果你对MRI比较熟悉的话，这将是最简单的一个世界。
3.新增4个mini game
在选关画面的右边有4个mini game，可以进入的mini game个数由目前你已经解锁的Chapter个数确定。其收益还是不错的，用来休闲娱乐也可以哦。
***修改内容***
1.关卡难度梯度大幅度修改
原版关卡有很多难度不合理的关卡。这些关卡基本上也被我改的惨惨的。
主要简化关卡：**1-1**、1-5、1-6、1-！、2-4、2-6、3-3、**3-6**、3-7、**3-9**、**3-14**、**4-7**
主要加难关卡：4-4、4-10（冰部分）
特别说明：4-10由原来的一次性打掉3个部分的要求转变为各个击破，所以冰部分难度有所提升，但最终boss难度明显下降。
2.部分设定修改
初始生命由3条增至5条
剧情只有第一次进入才显示
3.主界面修改
pre-start界面翻新，新增两个链接
start界面重做，换成雪地背景（新年更新嘛233）
选关画面内容增加，成就栏增加Past World Completed成就
