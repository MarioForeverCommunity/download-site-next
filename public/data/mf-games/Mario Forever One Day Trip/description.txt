If you want to skip intro and start cutscene you can press "Escape" and if you want to delete the progress hold "Ctrl"+"Delete" during several seconds in the
start screen, after that write "Yes" in the pop-up window. ;)

In this version of the game you can use mouse, right click opened context menu ;) (special thanks to MrPrzemistrz for this idea)
"Helpful Arrows" (to determine where Mario or the enemy fireball/iceball/spikeball/hammer are currently located, if they are above the screen area;
special thanks to @krzyspasztecik12 for this cool idea) and "V-Sync" are also enabled by default.
You can change these settings in the settings section of the game menu.

IMPORTANT:
1. Default framerate is 50 FPS. Yes, you can change framerate to 60 FPS, but I wanna warning you: technically it will works not so good. I'm so sorry about it.
2. Please don't hold the button "Pause" if you use button "P" as pause button. If you'll hold that button cursor will be removed.
I don't know why it happened and I can't fix that. In this case I can offer you to change pause button in settings.
3. Unfortunately context menu doesn't work in Save Game Room.
But I think, it's not necessarily thing there, however, if you wanna come back to Main Menu you can always press F3.
