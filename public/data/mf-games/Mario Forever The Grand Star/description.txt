This is the second demo of my Mario Forever Fangame, The Grand Star, which is currently in development.
Newer versions will be released as time passes.

This fangame is NOT affiliated with Nintendo, and I am making NO profit out of it. All assets belong to their
original creators.


The game by default runs with the Compatibility renderer.

If your computer supports Vulkan/Forward+ graphics, please run the game with the file:
"00. Launch in Forward+ Mode (Vulkan).bat"

If, for some reason, you open the executable file and it doesn't open/stays stuck in a blank screen, try using the .bat 
files to launch the game in Compatibility Mode (compatible with OpenGL devices).


Any skins made in the latest version of Mario Forever: Community Edition should be compatible with this game.
