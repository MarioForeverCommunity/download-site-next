发图，然后说明此游戏的一些与其他不同的地方。
首先，原来的名字是雨夜Rain Night，后来由于城堡关穿越了所以改名了= =
下载地址：[http://kc.cc/SZgz](http://kc.cc/SZgz) （百度奇葩的传不上，总失败；文件太大永硕也传不了；因此只能是金山快盘了）
引擎：RE
难度：★★★★☆
注意事项：游戏比较坑，所以一路上无数的绿蘑菇等待着你去寻找（当然是隐藏绿蘑菇，自己去顶吧，看能不能人品顶到绿蘑菇），然后注意红色食人花**会喷很多火球并且像蓝花一样马里奥站在上面还是会受伤的！！！！**
游戏共有四关，其中第三关是迷宫。
游戏不难但是挺坑，要耐心一点，尤其是到了后期越快越容易死（你自己玩到那你就知道了，会很漫长的说= =）
后面的穿越不分不发了，自己去过关看看吧= =（按理来说你就凭着四条命前三关应该很简单的，也许这是我这制作者效应吧= =我测试了不只几十遍了，地图背都能背下来了）
