RT，这是我将我在2015-2017年间为我当时计划制作的大作品中已经完成的关卡翻新并整合而来的作品。

## 游戏说明：
本游戏共有6各关卡，4种难度。总计24个关卡frame。
可在游戏设置中开启 Fast Retry。

## 翻新说明
- 添加了难度选择和选关界面
- 使用 CTF R294.14 构建
- 将原本通过 Sub Application 拆散的关卡整合到一个应用程序中
- 将外置 BGM 改为内置 BGM，并压缩 BGM 体积
- 添加了一套新的 BGM，可在游戏设置中选择使用旧版还是新版 BGM
- 修复了隐藏砖没有实心的 bug（
- 修复了一些游戏错误
- 更改了开场动画中一处可能有争议的地方
