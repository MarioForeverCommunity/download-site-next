01. Info
"Super Mario Forever 2014 Deluxe", as you are going to play, is the deluxe version of "Super Mario Forever 2014" (first released in July 20, 2014).

As you know, the original version of "Super Mario Forever 2014" only have 9 worlds, 38 levels, which doesn't meet the plan I had ever made because I have no much time to complete my plan in 2014.
Now I remake the original version of "Super Mario Forever 2014", and add some new levels. Besides, some design of level are adjusted, too. Now the deluxe version have 10 worlds in total.
Enjoy the game!

03. How to Play this Game 

*The recommended keys are:
Z: Jump / Start a level
X: Run / Shoot Fireballs
Left / Right: Move / Run (with "X" pressed) / Enter a horizontal pipe
Up / Down: Crouch / Change a option / Enter a vertical pipe
Enter: Select an option

*You can change all the settings in "options" as your preferences.
