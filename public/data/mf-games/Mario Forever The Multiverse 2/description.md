**The Multiverse 2** is another notable collaboration release by Meteo Dream (formerly known as Team CE) after All Stars 3, released in December 2022. This time, on a much bigger scale and with new mechanics.

One of the first experiences with Godot Engine, with experimental and unique features and mechanics, some of which may feel slightly off nowadays.

### v1.3 Changelog

- Added a toggle for 1.2x game speed.
- Added an option to change window scale.
- Added a few effects on MAX quality, similar to Thunder Engine (e.g. coin collection, score text).
- Replaced the previous viewport filter with the one from Thunder Engine, and added a new option for full bilinear filter.
- Changed the appearance of text in a lot of places.
- Added new particles to some levels, and changed existing particles a bit (e.g. Hypersomnia Caves, The Cloudverse-3.
- Added a circle transition from save room in some cases.
- Added an explanation sign to The Hellverse-3.
- Added thunder effects to The Multiverse 1-4.
- Treasure Tanks requirements are more consistent now.
- Removed useless Discord RPC integration.
- Some graphics have been updated.
- Shaders in Desert Eagle are much less intense now.
- The soundtrack in The Multiverse 1-3's bonus room has been reverted back to the original version.
- Added water splash and underwater bubble effects.

**Bug Fixes**
A lot of bugs have been fixed, some examples are:

- Fixed enemies walking on each other.
- Fixed the game breaking apart on high framerates.
- Fixed enemy fireballs and some projectiles disappearing from the screen too early.
- Sound effects volume is much more consistent across the game now.
- Game is much less crash-prone now.
- Game should have much less stutters with particles now.
- Fixed a water exploit in The Multiverse 1-3.
- Fixed a possible softlock with transitions.
- Fixed being unable to stomp enemies while moving upwards.
- Fixed platforms being desynced while standing on top of them.
- Fixed Spinies turning around corners randomly.
- Fixed a bug where the player would not get hurt in some cases.
- Fixed the timer being off by one.
- Fixed the timer being empty immediately after loading a level.
- Fixed lag caused by Lava Lotuses in The Multiverse 1-2.
- Fixed Buzzy Beetles in The Hellverse-1 not moving in some situations.
- And many more bug fixes.
