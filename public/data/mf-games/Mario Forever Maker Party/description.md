**模式 | 各自制作、一起游玩**

和家人、同学、也包括线上的朋友们！

一起使用轻便简单的马力欧编辑器制作关卡！

随后随机拼接在一起，依次游玩！

**功能 | 拍摄收藏**

在联机游戏结束之后，可以返回历史记录查看和大家一起游玩过的关卡。

如果喜欢的话，还可以按下「摄影」键对关卡拍摄照片并收藏。

**特点 | 移动端支持**

本游戏使用 Godot 制作，目前已经支持 Windows 和 Android 平台。

不同平台的玩家也可以联机！
