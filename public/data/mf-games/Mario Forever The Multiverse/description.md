_**Additions and changes:**_

\- Swimming vertically in the 2nd level is now more smooth.

\- Ship flying away animation in Bowser's second phase is now more smooth.

\- Improved end gate sprites to fill blocks under them in 2nd, 3rd and A levels.

\- Added background pipe decorations to the 2nd level.
\- Giant Fish in the 3rd level now flies less frequently.

\- Beetle Shell in 4th level now uses the same sprite as in the 1st level.

\- Increased time in the 4th level from 560 to 600.

__**Removals:**__

\- Removed ability to kill Lava Lotuses with a star and a shell (there is no stars and turtles in the 2nd level wtf!)

\- Removed unused graphics from the game.

\- Removed unused objects from Bowser's second phase level.

__**Fixes:**__

\- Fixed flickering Mushroom appearing animation in Bowser's second phase in "FAST PC" version.

\- Fixed incorrect Mushroom behavior in Bowser's second phase. It now can go out of the game's window and then reappear after some time.

\- Fixed credits previously using beta version texture.

\- Fixed background glitches in some cases in the Overworld section of the 2nd level.

\- Fixed Mario in castle cutscene using incorrect powerup animations.

\- Anti-cheating system now actually works.

\- Music in save game room now can be muted.

\- Fireballs now behave correctly with some objects in save game room.

\- Shooting beetroots into some objects in save game room no longer corrupts Mario physics.

\- Warp to The Multiverse-A level from save game room now finally works after finding the level.
