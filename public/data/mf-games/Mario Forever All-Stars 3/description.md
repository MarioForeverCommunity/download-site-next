## About

**All Stars 3** is the first notable collaboration release for Meteo Dream (formerly known as Team CE and Team LJD), with a variedly themed world of 8 levels and unlockable extras. It is quite dated, but for historic purposes, it is available to download from here.

Since 1.0.5, the game was updated with more extra content months after initial release. You can look in the Old Versions folder for the older versions.

Collect Green Stars found among the levels to unlock Extra Levels. There're two endings!

Mario Forever All-Stars 3 has game over continues and save point at level 5.

Supports Discord Rich Presence; if you have Discord and you enabled showing games in status, you will see the level you're on. You can disable this in game options if you don't have Discord.

Does no longer have randomized jump height. That means speedrunning the game will be easier.

Don't forget to update the game (by pressing Z and then Enter) when you see a text "Found an Update!" in the game loading screen to have a more stable version of the game and, possibly, new extra levels!
