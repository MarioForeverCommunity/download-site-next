_This isn't new at all, but I consider it like a personnal experiment.
I mean I didn't created this to compete with Mario Forever Remake Team. It was for me just an attempt to remake the exact Mario Forever, or improving it with its style ( The game is built with MMF1.5 )_

Anyway, you will play a sort of version-mix of Mario Forever, it's based on version 1.15 ( From my memory ) with some features from others ( From maximum version 4.4 ), thus the difficulty in some levels were restored. I also changed ( The emplacement of ) some extras, and organized the Save Game Room differently.
