		Thanks for have downloaded Mario Forever - Lost Map 2!

As the name may suggest, this game is a continuation of Mario Forever Lost Map, a fangame made firstly by Michal "Buziol" Gdaniec with with Multimedia Fusion 1.2.
This game is made with Clickteam Fusion 2.5.

===============================================================
01. IMPORTAN NOTES:
DO NOT delete for any reasons the mafosav.ini, it's very important for the game's save settings.

===============================================================
02. Controls

X = Run/Shoot fireballs
Z = Jump/Start level
Left and right arrows = Move left/right
