## Mario Forever, but Floor is Lava

It's just Mario Forever, but every single level has flooded with lava! The whole 8 worlds, Human Lab and a few extra levels were modified to have lava instead of the usual grassy ground. It may require some advanced skills, so I made a little tutorial level and a lot of explanatory signs on main levels (if difficulty is not "Original") to help the player.

Be sure to install the included redistributable.
