		Thanks for have downloaded Mario Forever Fanmade - version 4.0 beta!

Mario Forever Fanmade is a Mario Forever game developed graphicwise and codewise by Mariovariable3410,
but all the levels are originally by fans, hence the name of the game. All the worlds available in the game are the first ranked worlds
in Mariovariable's "Mario Worker: The Contests", starting with World 0 by Crist1919 and going on with the next contests.

Originally part of Mario Forever Remake, the first ranked worlds by other users are now completely part of a great new adventure.

===============================================================
01. Infos

The remake contains all the 8 standard worlds with some, if not much, custom elements for make it a bit different
from the original, such custom special worlds and extras, which aren't included in the original Mario Forever
(World 9 excluded, as MF6.0 has it).

To make musics work, extract the "data" folder from its .rar archive, and place it in the game's folder.

===============================================================
03. Controls

X = Run/Shoot fireballs
Z = Jump/Start level
Left and right arrows = Move left/right
CTRL+J = Hide top bar
CTRL+H = Show top bar
1 / 2 = Choose the world in Save Game Room.
