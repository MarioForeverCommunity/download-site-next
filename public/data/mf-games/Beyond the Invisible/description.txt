Mario Worker Level Remake: Beyond the Invisible
=====================================================
1. Info
This game is a remake of zqh__123's Mario Worker 1.1 level: Beyond the Invisible.
=====================================================
2. Default Controls
Z - Jump
X - Run
Left / Right Arrow: Move left / right
F1 - Show "About" dialogBox
F2 - Restart game
