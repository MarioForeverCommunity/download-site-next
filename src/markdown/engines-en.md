## Clickteam Fusion 2.5
Clickteam Fusion, formerly known as Multimedia Fusion and abbreviated as MMF or CTF, is a multimedial software-creator application developed by the software company Clickteam. The program allows users to build and test their own software using event-based programming languages they create themselves. Most famous games were made with Multimedia Fusion, including the Five Nights at Freddy's series. This is the program that was used by Michał Gdaniec to create his games and Mario Forever, as well as other MF users, to build and make subsequent fangames based on it.

### Mario Forever Engines on Clickteam Fusion
#### Mario Forever Editor
MarioForeverEditorV1.cca is the source file bundled with the Mario Worker 1.0 installer. It cannot be used directly as a game template or engine after being opened in Multimedia Fusion; extensive manual modification is required. Due to the limitations of Multimedia Fusion 1.5, all events within a single frame are placed in the main event list, making the project difficult to maintain and further develop.

Note: Not to be confused with Mario Forever Engine by Dunami.

#### World 10 Engine / Mario Forever Remake Engine
This engine is an improved version based on MarioForeverEditorV1.cca. It is one of the earliest directly usable Mario Forever engines. Depending on the levels included when the engine was released, it is commonly referred to as either the World 10 Engine or the Mario Forever Remake Engine. This engine is less maintainable and less suitable for further development than other engines, and requires a strong foundation in using Multimedia Fusion.

#### Cloud Engine
Cloud Engine is a Mario Forever engine created by Meteo Dream (formerly Team CE), based on MarioForeverEditorV1.cca. It was designed with the goal of achieving better user-friendliness, usability, and stability while maintaining the legacy of the original Mario Forever players know and love. It features most of the original content from Mario Forever, while adding custom features on top of it and remaining clean and lightweight. Cloud Engine also takes advantage of the sub-event feature introduced in Clickteam Fusion 2.5+, making it one of the easier-to-use Mario Forever engines.

#### Feather Engine
Feather Engine is an engine created by TheMarioVariable as a complete update of the original MarioForeverEditorV1.cca file. It features every item, graphic, sprite, and physics element from the classic Mario Forever games released prior to v4.0. While retaining much of the original coding structure, the engine has been updated for Clickteam Fusion 2.5, with the code made more understandable and the addition of instructions to improve user-friendliness. The engine is named Feather Engine because of its lightweight size of less than 8 MB overall.

#### Rainbow Engine
Rainbow Engine is a Mario Forever engine created by Lyh. The engine was built entirely from scratch, so it differs slightly in certain details from engines based on MarioForeverEditorV1.cca.

In Rainbow Engine, many objects have behaviors created for them, allowing events to be written directly into the relevant objects. As a result, creating new enemies can eliminate some repetitive work through copy and paste. However, since Clickteam Fusion 2.5 does not support referencing Groups within behaviors, events involving Groups still have to remain in the main event list.

Rainbow Engine is easy to get started with and does a good job of reproducing the original Mario Forever. Most Chinese fangames are made with this engine or with versions derived from it.

#### Spectrum Engine
Spectrum Engine (formerly Rainbow Engine Mod) adds new enemies, facilities, and powerups to Rainbow Engine, fixes bugs, and localizes most of the main content into English.

#### Super Mario Ultra Edition
In 2020, Clickteam Fusion 2.5+ was updated to allow **sub-events** and **referencing Groups inside behaviors**. Against this background, Super Mario Ultra Edition, created by dasasdhba, was released. This engine was also built from scratch, and it makes good use of the structure and features of Clickteam Fusion 2.5+. The entire engine features rigorous collision detection and a well-organized system, providing plenty of interfaces for secondary development. However, using it requires a certain understanding of the engine itself. This engine does not focus on reproducing the original Mario Forever; rather, it aims to make creating, developing, and playing more comfortable in every aspect. Some Chinese fangames released since 2021 have been made with this engine.

## Godot Engine
Godot is an open-source game engine capable of making both 2D and 3D games. Games are designed through a node-based architecture. Godot allows game developers to create games using multiple programming languages, such as C++, C#, and GDScript.

<a class="md-button" target="_blank" href="https://godotengine.org/">Godot Engine Official Website</a>

Godot is a powerful game development platform. Using Godot may require a comprehensive understanding of the engine itself, coding, MF games, and game templates, so it has a relatively high learning curve.

With the rise of Godot, some community members have tried creating Mario Forever game templates on Godot. Currently, the most widely used one is the Thunder Engine for Godot 4, made by Meteo Dream; in addition, there is a Mario Forever Mole Editor by ChloePrime.
