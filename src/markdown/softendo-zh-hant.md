本目錄收錄所有 Mario Forever、Mario 和 Non-Mario 以外，與 Softendo／Buziol Games 有關的遊戲，包括由其製作、重新封裝、在遊戲製作名單中列名，或以其他方式與其有所關聯的作品。這也包括 Banesoft 的遊戲（其做法只是取得 Buziol 的遊戲專案檔案，重新封裝成不同的遊戲）、在某種程度上列有 Buziol 名稱的 Skell Zoft 遊戲，以及由粉絲或合作夥伴製作、再由 Buziol 以自有品牌發行的遊戲（主要是 Flash 遊戲）。

由於這些遊戲使用較舊的引擎及作業系統製作，部分遊戲可能無法在你的電腦上正常運作，甚至完全無法執行。因此，這類遊戲通常需要使用較舊的電腦，或是在執行舊版作業系統的虛擬機器中運行，並搭配必要的驅動程式及／或設定，才能正常遊玩。

每款遊戲均標示以下資訊：
- 類型（Mario、Non-Mario、Banesoft 等）
- 引擎（遊戲所使用的引擎）
- 語言（英文、波蘭文或兩者皆有）
- 遊戲類型（例如解謎、益智遊戲、清版射擊遊戲等）

部分遊戲的玩法風格相近，也有一些作品尚未完成。此外，部分遊戲在同一引擎下可能有多個不同的版本，例如 Super Mario Dark Dungeon 的 Flash 版本，分別標記為 (swf 1)、(swf 2) 和 (swf 3)。

其中有少數遊戲僅提供波蘭文版本。

每款遊戲的條目中均提供該遊戲特定版本的下載連結。每個版本都有專屬的顏色標記，以區分其提供的檔案類型：
- 藍色：遊戲安裝程式。
- 橘色：遊戲安裝程式，附帶可選的工具列套件。
- 綠色：遊戲的獨立 EXE 執行檔，可在電腦上的任何位置直接執行。
- 紫色：ZIP／7z 壓縮檔，內含免安裝版遊戲，可輕鬆解壓縮後直接遊玩，且已移除不必要的廣告檔案。
- 紅色：遊戲的 SWF 檔案，僅適用於 Flash 遊戲。
- 粉紅色：WinRAR SFX（Self Extracting Archive，自解壓縮檔）。這是一種附帶簡易介面的特殊壓縮檔，會像安裝程式一樣將遊戲檔案解壓縮至自身所在的資料夾，不會將檔案寫入 Program Files 或系統登錄檔，也不會安裝工具列。此類檔案不需要使用 WinRAR 或 7-Zip 等壓縮軟體即可執行。
- 青綠色：由 Kliktopia 重新封裝的遊戲版本，僅提供免安裝格式，且只適用於 Non-Mario 遊戲。
