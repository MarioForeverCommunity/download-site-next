本目錄旨在收集並保存 Mario Forever 同人遊戲，讓玩家能夠輕鬆尋找、下載及遊玩這些作品。

**本目錄並非用於推薦同人遊戲。** 本目錄僅是一個持續擴充的保存檔案庫，目的是保存同人遊戲並提供便利的存取方式。因此，我們不會對收錄的遊戲設定任何品質門檻，建議你在遊玩任何同人遊戲之前，先自行了解該作品的相關資訊。

只有在以下情況下，才會*移除*同人遊戲：

- 遊戲作者基於任何原因，要求將其作品從目錄中移除。
- 遊戲侵犯其他創作者的權利（例如：遊戲是以其他同人遊戲的反編譯版本為基礎製作、盜用其他同人遊戲的素材等）。
- 遊戲包含病毒、惡意軟體或其他可能損害使用者裝置的有害檔案。
- 遊戲包含不適當或違法的議題／主題。
- 遊戲本身存在爭議。

如果你遇到以下任何情況：

- 你發現某款同人遊戲符合上述任何一項移除條件，但目前仍未從目錄中移除。
- 目錄中缺少某款同人遊戲，無論是你自己的作品還是其他人的作品。
- 你發現連結失效或連結內容不符。
- 你發現資訊有所缺漏、錯誤或過時。
- 你是同人遊戲作者，並基於任何原因希望將自己的作品或其中某個特定版本從目錄中移除。
- 或者你有其他重要的疑慮。

請[在網站的 GitHub 儲存庫中提交 Issue](https://github.com/MarioForeverCommunity/download-site-next/issues/new/choose)，或[透過 Discord 私訊聯絡維護者](discord://-/users/406048815460646912)。我們會盡快完成任何必要的移除、新增或修正。

同人遊戲可依照以下條件區分：

- 地區（篩選中國或海外製作的同人遊戲）
- 平台（同人遊戲所支援的作業系統）
- 軟體（製作同人遊戲所使用的遊戲引擎）
- 標籤（例如合作、愚人節、硬核、聖誕節等，並支援同時選取多個標籤。）

部分同人遊戲的舊版本可在 [社群資源網站](https://file.marioforever.net/mario-forever/games/) 中找到。
