每款游戏均包含以下信息：类型、引擎、语言、游戏类型（可通过标签筛选）。

部分游戏的玩法风格相近，也有一些作品尚未完成。此外，部分游戏在同一引擎下可能有多个不同的版本，例如 Super Mario Dark Dungeon 的 Flash 版本，分别标记为 (swf 1)、(swf 2) 和 (swf 3)。

其中有少数游戏仅提供波兰语版本。

每款游戏的条目中均提供该游戏特定版本的下载链接。每个版本都有专属的颜色标记，以区分其提供的文件类型：
- 蓝色：游戏安装程序。
- 橙色：游戏安装程序，附带 Mario Forever Toolbar。
- 绿色：游戏的独立 EXE 可执行文件，可在电脑上的任何位置直接运行。
- 紫色：ZIP / 7z 压缩包，内含绿色版游戏，可解压后直接游玩，且已移除不必要的附加文件。
- 红色：游戏的 SWF 文件，仅适用于 Flash 游戏。
- 粉色：WinRAR 自解压压缩包。这是一种附带简易界面的特殊压缩包，会像安装程序一样将游戏文件解压到自身所在的文件夹，不会将文件写入 Program Files 或系统注册表，也不会安装 Mario Forever Toolbar。此类文件无需使用压缩软件即可运行。
- 青绿色：由 Kliktopia 重新封装的游戏版本，仅提供绿色版格式，且只适用于 Non-Mario 游戏。
